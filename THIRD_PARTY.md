# Third-party references

The binary layout follows the public ESRI Shapefile Technical Description.
The implementation is a clean MoonBit implementation and does not copy ESRI
software or code.

The DBF API is informed by PyShp (https://github.com/GeospatialPython/pyshp,
MIT License). No PyShp source is bundled. Compatibility fixtures are created
independently and are not redistributed from upstream.
