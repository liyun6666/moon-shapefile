## 提交前需要处理的问题

1. **高优先级：Dataset 联合读取错误拒绝合法 Latin1 数据。** `dataset.mbt` 的 `read_dataset` 按指定编码读取 DBF 后调用 `Dataset::validate`，后者调用固定按 UTF-8 宽度检查的 `@dbf.validate_table`。宽度为 1、值为 é 的 Latin1 字符列能通过 DBF 独立读写，却在联合读取时抛出 ShapeError.InvalidData。`write_dataset` 同样先走此校验。修复应使校验与所选编码一致，并覆盖读写回归。
   本次临时探针：构造 Point 及上述属性表，DBF Latin1 往返断言通过，随后 read_dataset 失败；共 48 测试，47 通过、1 失败。探针已删除，未修改业务源码。
2. **高优先级：GeoJSON 数据集导出静默丢失属性。** `dataset.mbt:156` 对所有 Feature 固定输出 properties:null，未映射 DBF 字段和值。对于属性联合处理与 GIS 数据交换用途，这是实质功能缺口。应补齐类型映射与字段值断言；若明确只支持几何导出，则必须在 API 与文档中披露边界。
3. **中优先级：可执行示例没有展示库功能。** `cmd/main/main.mbt` 仅打印项目名称；README 有几何片段，但缺少依赖安装、包导入和完整入口。应提供能直接运行的 SHP/SHX/DBF 联合读写及 GeoJSON 示例，并验证数据值。
4. **中优先级：CI 格式检查没有形成约束。** `.github/workflows/moon.yml` 执行 moon fmt，会直接格式化且不检查差异。建议改成 moon fmt --check。本地本次格式检查实际通过，此项不是现有格式错误。
